# AI-Powered DevSecOps

AI-Powered DevSecOps is a secure CI/CD pipeline project with cloud security monitoring.

## Features

- User Registration and Login
- JWT Authentication
- CI/CD Pipeline Management
- Vulnerability Detection
- Security Score
- AI Security Analysis
- Cloud Monitoring
- Security Reports
- PDF Report Generation

## Technologies

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- PDFKit
