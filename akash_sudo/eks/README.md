# EKS Security

Phase 2 will implement only the security controls assigned to the Cloud Security Engineer:

- private worker subnets
- EKS endpoint access strategy
- cluster/workload security groups
- Kubernetes RBAC
- Pod Security Standards
- default-deny NetworkPolicies
- EKS Pod Identity/IRSA
- least-privilege workload IAM
- audit logging
- ECR image-digest verification

No application manifests are owned by this workstream.
